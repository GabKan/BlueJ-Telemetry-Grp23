# BlueJ Telemetry Plugin

This project builds a BlueJ extension that records basic compilation events. The instructions below put Windows first; Linux instructions follow.

## Windows setup

### Requirements

- BlueJ installed on the computer.
- A Java 17 or newer JDK and Maven available in a terminal.
- The BlueJ API file `bluej.jar`. Find this file inside the BlueJ installation; the Maven setting must point to the **directory that directly contains** `bluej.jar`.

### Build and install

Run these commands from the repository folder (the folder containing `pom.xml`). Replace the example BlueJ path with the directory where you found `bluej.jar`:

```powershell
mvn package "-Dbluej.home=C:/Program Files/BlueJ"
New-Item -ItemType Directory -Force "$env:USERPROFILE\bluej\extensions2"
Copy-Item "target\bluej-telemetry-plugin-1.0.0.jar" "$env:USERPROFILE\bluej\extensions2\"
```

If the BlueJ installation puts `bluej.jar` in a subfolder, use that subfolder as `bluej.home`. For example, if the file is at `C:\Program Files\BlueJ\lib\bluej.jar`, set `bluej.home` to `C:/Program Files/BlueJ/lib`.

Restart BlueJ after copying the extension. BlueJ 5 and later use `%USERPROFILE%\bluej\extensions2` on Windows. Older BlueJ versions may use a different extension folder.

Open a BlueJ project and compile a class to check that the extension is working. The file `bluej-telemetry.log` should appear in that BlueJ project's root folder.

## Linux setup

The current Linux configuration expects `/opt/bluej/bluej.jar`. From the repository folder, build and install the extension with:

```bash
mvn package -Dbluej.home=/opt/bluej
mkdir -p ~/.bluej/extensions2
cp target/bluej-telemetry-plugin-1.0.0.jar ~/.bluej/extensions2/
```

If BlueJ is installed elsewhere, set `bluej.home` (located in the `pom.xml` file) to the directory that directly contains `bluej.jar`. Restart BlueJ, open a project, and compile a class. BlueJ 6 uses `~/.bluej/extensions2/`; older BlueJ versions may use `~/.bluej/extensions/`.

## What the files and folders are

| File or folder | What it is and where it belongs |
| --- | --- |
| `pom.xml` | Maven build configuration. It is in the repository root, beside this README. It sets the Java version, plugin artifact name/version, and BlueJ API location. |
| `bluej.jar` | BlueJ's extension API, supplied with the BlueJ installation. It is not generated by this project and normally should not be copied into the repository. Set `bluej.home` to its containing directory so Maven can find it. |
| `target/bluej-telemetry-plugin-1.0.0.jar` | The built extension JAR. Maven generates it in the repository's `target` folder when `mvn package` succeeds. Copy this JAR to BlueJ's user extensions folder; do not copy the whole `target` folder. |
| `extensions2/` | BlueJ 5 and later's per-user extension folder. On Windows this is `%USERPROFILE%\bluej\extensions2\`; on Linux it is `~/.bluej/extensions2/`. Create it if it does not exist. The extension JAR goes here. Check your BlueJ version's documentation if its extension folder differs. |
| `package.bluej` | A BlueJ project settings/marker file created by BlueJ in each project. Keep it in the project; the extension searches upward from compiled source files to find the project root. |
| `bluej-telemetry.log` | A human-readable event log created by the extension in the BlueJ project root the first time a compile event is recorded. It is not created by the Maven build. |

## Build and run

### Requirements

- JDK 17 or newer (JDK 21 recommended, the same as BlueJ 6)
- Apache Maven 3.9 or newer
- BlueJ 6.0.1 (only needed to run the extension, not to build it)
- VS Code users: install the "Extension Pack for Java"

Run `mvn -v` and check that Maven uses the JDK you expect.

### Build

No manual setup is needed. The BlueJ API jar is stored in the `lib-repo`
folder of this repository, and `pom.xml` reads it from there.

```bash
git clone https://github.com/GabKan/BlueJ-Telemetry-Grp23.git
cd BlueJ-Telemetry-Grp23
mvn clean verify
```

The plugin jar is created at `target/bluej-telemetry-plugin-1.0.0.jar`.

### Run the tests

```bash
mvn test
```

Coverage report: run `mvn clean test jacoco:report`, then open
`target/site/jacoco/index.html`.

### Install in BlueJ

Copy `target/bluej-telemetry-plugin-1.0.0.jar` into the BlueJ extensions
folder, then restart BlueJ.

### Troubleshooting

| Problem | Cause | Fix |
|---|---|---|
| VS Code shows "Could not read maven project" | The Java extension kept an old error | Run **Java: Clean Java Language Server Workspace**, restart, then right-click `pom.xml` and select **Update Project** |
| Maven says the BlueJ jar "was not found" | A failed lookup is cached | Run `mvn -U clean verify` |
| `Unsupported class file major version` from JaCoCo | The JDK is newer than the JaCoCo version supports | Use JDK 21, or update `jacoco-maven-plugin` |
| Maven cannot find `lib-repo` files | The folder is missing from your clone | Run `git ls-files lib-repo` and pull the latest changes |
